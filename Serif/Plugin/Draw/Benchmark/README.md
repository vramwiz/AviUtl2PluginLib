# SerifDraw 文字描画ベンチマーク

SerifDraw の装飾済み文字画像を生成する方式を比較する独立サンプルです。プラグイン本体や AviUtl2 は変更しません。

比較条件は次のとおりです。

- 文字列: `SerifDraw LARGE TEXT`
- フォントサイズ: 520px
- 装飾: 白い本文、48px の青い縁取り
- 出力: 透明 RGBA
- 計測: Release / Win64、5回ウォームアップ後に30回
- サイズ: 3840x2160 と 3840x800

比較方式:

- GDI+ 現行相当: サーフェス、文字パス、装飾オブジェクトを生成して描画し、BGRAからRGBAへ変換
- GDI+ キャッシュ: 文字パスまたはサーフェスも再利用
- Skia simple-text: RGBAバッファへ直接、輪郭と本文を描画
- Skia text-blob: 字形列もキャッシュしてRGBAバッファへ直接描画

`build_and_run.cmd` を実行すると、Delphi 13 / Studio 37 の Win64 コンパイラでビルドし、必要な `sk4d.dll` を実行フォルダーへコピーして計測します。

結果は `Win64\Release\results\benchmark.csv` に保存されます。GDI+とSkiaのプレビューPNGも同じフォルダーに生成されるため、何も描画せず高速になっていないことと、装飾の見た目を確認できます。

GDI+とSkiaではフォントエンジンが異なるため、字形の位置とアンチエイリアスは完全なピクセル一致にはなりません。白い本文と丸い青縁を持つ同じ種類の出力として、速度と品質の両方を評価します。
