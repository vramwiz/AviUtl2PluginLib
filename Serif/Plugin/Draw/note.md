# SerifDraw 現行仕様・設計ノート

このファイルには、今後の検討・実装に必要な現在の仕様と未実装方針だけを記録する。
完了済み作業の時系列記録は [`note_history.md`](note_history.md) を参照する。

## 対象

- 共通実装: `AviUtl2PluginLib\Serif\Plugin\Draw`
- Syncroh2プロジェクト: `Syncroh2_Filter_SerifDraw.dproj`
- MMDプロジェクト: `MMDAnimationStudio\MMD_Serif_Draw_Filter.dproj`
- 製品別の公開名、グループ名、情報文字列、診断先は各プロジェクトの`SerifDrawProfile`で登録する。
- AviUtl2用出力: `Plugin\Syncroh2\Syncroh2_Filter_SerifDraw.auf2`と`Plugin\MMD\MMD_Serif_Draw_Filter.auf2`
- セリフ送信Module: `Syncroh2_Module.dproj`
- Module出力: `C:\ProgramData\aviutl2\Script\Syncroh2\Syncroh2_Module.mod2`
- 設定画面ではアニメーションを扱わず、セリフ、配役、枠の編集だけを行う。アニメーションは
  AviUtl2オブジェクトのフィルターパラメーターとして設定する。

## ユニット構成

- `Animation`: アニメーションの型、フィルターテーブル項目、評価、状態管理、同期位置計算。
- `Display`: Skia描画、配置、複数セリフ合成、枠、配役名。
- `Editor`: 設定フォーム、プレビュー、ドラッグ操作、編集用コントロール。
- 共通文字描画は `AviUtl2PluginLib/TextRenderer` を利用する。`TTextRenderImage.LayoutBounds`は本文全体、
  `LineLayoutBounds`は中央／右寄せや文字間隔を反映した行ごとの実測配置範囲を保持する。

## 専用編集画面のDirect2D移行

- PSDプレビューで実績のある`TDirect2DCanvas`方式を、専用編集画面のプレビューへ段階的に移行する。
- 第一段階として、背景、セリフ文字、配役名の拡大合成をDirect2Dへ移した。枠本体と編集ハンドルは
  従来のGDI描画を維持し、表示順も背景、枠、文字、編集ハンドルの順を保つ。
- Direct2D非対応環境または描画初期化に失敗した場合は、その画面セッション中だけ従来GDI経路へ
  自動的に戻す。失敗理由はDebugログへ記録する。
- Debug / Win64はビルド・PostBuild配置済み。AviUtl2を再起動し、文字、配役名、半透明枠、
  ズーム、パン、各ドラッグ操作の表示と応答速度を確認する必要がある。
- 実機初回確認では文字移動は高速化したが、文字サイズ変更はマウス移動ごとにCPU Skiaで本文と
  配役名を再生成していたため重かった。サイズドラッグ中は既存文字画像を配置アンカー基準で
  一時拡大し、マウスを離した時だけ最終サイズを再生成する方式へ変更した。
- 画面生成時に全VCLフォントへ`TSkTypeface.MakeFromName`を実行する存在確認は廃止した。
  VCLのインストール済みフォント一覧をそのまま表示し、実描画時の既存フォールバックを利用する。
- 文字と配役名の縁取り幅、縁ぼかし、影ぼかしはpxから文字サイズ比（%）へ変更した。
  縁取りは0〜100% / 120px、縁ぼかしと影ぼかしは0〜20% / 40pxを上限とする。
  Skiaのぼかし領域は半径の3倍まで確保するため、20%で見た目の広がりを約60%に抑える。
  影オフセットは各軸±60% / 120px、影広がりは0〜30% / 60pxの文字サイズ比とする。
  縁取り既定値は30%で、54px文字の従来16pxとほぼ同じ見た目にする。枠寸法はpxを維持する。
- 縁取り幅・縁ぼかしのドラッグ中は、変更していない配役名または本文の伴走プレビューを
  再生成せず再利用し、各マウス移動でのSkia文字生成を1回に減らす。
- すべての装飾ハンドルは設定値で移動させず、ドラッグ中も固定する。
  縁取りを親として縁ぼかしを横に並べ、影位置を親として影ぼかしを縦、影広がりを横に並べる。
  点線は本文から親装飾、親装飾から子装飾へ結び、効果の関連を表す。
- 装飾ハンドルのA本体は白または白い輪郭とし、影とぼかしの装飾部分だけを
  明るめの水色にする。ぼかしは白いAの周囲へ水色を重ね、色相で効果を識別できるようにする。
- 右上の縁取り・縁ぼかしは南西↔北東カーソル、右下の影ぼかし・影広がりは
  北西↔南東カーソルとする。どちらも文字から斜めに離すと増え、近づけると減る。
  影位置は全方向カーソルとX/Y独立ドラッグを維持する。
- 互換性は不要とし、保存形式を`SD7`へ更新して`SD6`以前は読み込まない。
- 次段階では実機結果を基に、枠描画のDirect2D化、D2D Bitmapの再利用、連続変更イベントの集約を判断する。

## セリフ受信と表示

- `@Syncroh2_Script.obj2`からDelphi Moduleの`set_text`へセリフ情報を渡し、共有メモリと
  `SerifSharedIndex`を経由してSerifDrawが現在フレームの有効セリフを受信する。
- 主要共有値は、UID、送信元Object ID、レイヤー、セリフ、配役、感情、方向、相対フレーム、FPS、
  総時間、LAB、LAB有無、`speech_progress`、`speech_active`、`total_frames`。
- 同時に同じ本文を話す複数配役は、完成文字画像を配役数で均等な帯へ分け、送信順が古いものから
  新しいものへ合成する。配役名は個別名を並べず、重複人数を「2人」など1件で表示する。
- 複数セリフの手動並び方向・間隔UIは廃止済み。現在の特殊表示を標準動作とする。
- セリフ、配役名、キャラ別枠のスタイルは正規化した配役名へ関連付ける。保存形式は`SD7`。

## 現在のアニメーションパラメーター

項目名はAviUtl2全体で衝突しないよう、グループ名を含む一意な名前にする。

- 表示前: `前 種類`、`前 方向`、`前 奥行き`、`前 値1`
- 常時: `常時 感情表現`、`常時 速さ`
- 同期: `同期 種類`、`同期 色塗り`、`同期 通過後`、`同期 形`、`同期 色`、
  `同期 サイズ`、`同期 オフセットX/Y`
- 表示後: `後 種類`、`後 方向`、`後 奥行き`、`後 値1`

実処理へ接続済みの効果は次のとおり。他の候補は選択しても現在は無加工表示となる。

- 表示前: フェードイン、スライドイン、ズームイン、ポップイン、ワイプイン、ブラーイン、回転イン、バウンドイン。
- 常時: 感情表現のみ。共通変換で喜・怒・哀・楽を自動判定する。
- 同期: 色変え、前面、背面、下線、拡大、発光、ジャンプ。
- 表示後: フェードアウト、スライドアウト、ズームアウト、ワイプアウト、ブラーアウト、回転アウト。

## 同期アニメーションの実証結果

### 発音中文字色

- 色塗りを`文字単位 / なめらか`、通過後を`戻す / 維持`へ分離した。色変えは4組み合わせに対応済み。
- なめらかは独立文字画像の実画素範囲を左から塗る。戻すは現在文字内だけ、維持は通過文字の色を残す。
- 旧`標準 / 軌跡`の動作値は、それぞれ`戻す / 維持`に対応する。
- 維持はLABのPause／無音区間でも解除せず、完了済み発音要素数から進捗を保持して色位置の後退を防ぐ。
- 最終LABの後に現在LAB行が空になる末尾無音でも、完了済み発音要素数から進捗1.0を維持する。
  全体時間比へ戻して最終文字から1文字前へ後退させない。先頭LAB前の無音は進捗0.0とする。
- なめらか＋戻すの同期サイズは移動色帯の幅とし、100%を約1文字、500%を約5文字幅として文字境界を越える。
  なめらか＋維持では現在文字内の先端塗り幅倍率として扱う。
- 前面・背面・下線・拡大・発光・ジャンプは文字単位に対応済み。戻すは現在文字のみ、維持は現在文字まで
  完成状態を個別に保持する。前面は背面の文字領域計算を共用し、下線は実測文字幅の専用領域を使用する。
  前面・背面・下線のなめらかは従来の連続移動と連続軌跡を維持する。
- 前面・背面・下線の文字別実測範囲は文字単位モードでだけ取得し、なめらかモードの描画負荷を増やさない。
- 文字単位の横位置は各字形の実測範囲を使うが、前面・背面の中心Yと高さ、および下線Yと太さは
  所属行の共通矩形から求める。字形や句読点ごとの上下端の差でマーカーが波打たないようにする。
- 拡大のなめらかは行画像の局所逆変換として試作中。サイズ=最大倍率、オフセットX=推移幅、
  オフセットY=見た目の上下移動とし、正値で下、負値で上へ動かす。
- ジャンプのなめらかは行画像の局所Y変形として実装。サイズ=跳躍量、オフセットX=推移幅、
  オフセットY=上下の追加移動量とし、維持時のスライドは許容仕様とする。

- ModuleがLABの現在発音要素から`speech_progress`と`speech_active`を作り、表示側が概算文字位置を
  固定黄色へ変更する。最後の発音要素は進捗1.0として最終文字へ必ず届かせる。
- LABの`Pause`、`vol:0`、現在行なしは無音として色を変更しない。

### 発音位置四角

- LABと無音判定を使わず、相対フレームと`total_frames`から1フレームごとの位置を求める。
- 全行の実測ピクセル幅を合計し、フレーム0を1行目左端、最終フレームを最終行右端へ対応させる。
  改行境界では前行右端の次に次行左端へ移る。中間再生も状態を持たず同じ位置を再現する。
- 現在は行高より上下左右6px大きい半透明青色の正方形を文字背面へ描画する。横方向は現在行の
  左右端でクリッピングする。色、余白、形状は検証用固定値。
- この試作により、Moduleからの時間情報を表示側で実ピクセルへ変換し、発音に同期した
  1フレーム単位のアニメーションが可能であることを実証済み。今後は同期効果の拡張を優先する。

## アニメーション4分類の確定方針

### 表示前

- 読み始めを遅らせないことを最優先とし、短時間ですばやく完了する少数の効果だけに限定する。
- ユーザーが時間を変更すると遅すぎる／速すぎる状態になるため、`前 時間`は削除済み。
  効果ごとに安全な固定時間を内部で持つ。フェード0.30秒、左48pxからのスライド0.18秒、
  72%からのズーム0.20秒、72%→108%→100%のポップ0.24秒を実装済み。
- 次段階として、左から全体を表示するワイプイン0.20秒と、半径6px相当から鮮明になるブラーイン
  0.18秒を実装済み。回転インは-8度・90%から0度・100%へ0.20秒、バウンドインは上32pxから着地し、7px跳ねて収束する0.26秒で実装済み。
- `前 方向`は標準・左・右・上・下から選び、スライド、ワイプ、バウンドの出現軸に適用する。
  回転は右指定時に回転方向を反転する。標準は従来の左スライド・左ワイプ・上バウンドを維持する。
- `前 奥行き`はズームインとポップインに適用する。ズームは奥から72%→100%、手前から128%→100%。
  ポップは奥から72%→108%→100%、手前から128%→92%→100%とする。
- タイプライター、文字フェードイン、文字せり上がりは、数フレームでの読みやすさと効果の成立が難しいため候補から除外した。
- アニメーション対象はセリフ本文だけとする。配役名と枠は固定表示し、将来動かす場合はセリフとは別の
  専用要素として設計する。

### 表示後

- 表示前より時間と演出内容に余裕を持たせる。`後 時間`は削除済みで、各効果の固定時間を使う。
  フェード0.30秒、スライド0.22秒、ズーム0.24秒、ワイプ0.22秒、ブラー0.24秒、回転0.26秒の固定動作とする。
- `後 方向`は標準・左・右・上・下。スライドとワイプの消失方向に使い、回転は左指定で回転方向を反転する。標準は右方向。
- `後 奥行き`はズームの到達側を奥へ72%、手前へ128%から選ぶ。従来候補の拡大アウトは手前指定へ統合した。
- 文字フェードアウト、文字落下、文字散開、崩壊、グリッチアウト、フラッシュアウトは候補から除外した。
- 現状は表示後の途中で次セリフが来ると旧セリフを破棄する。将来は旧セリフを一時バッファへ保持し、
  背面で表示後を継続しながら、新セリフの表示前・常時・同期を前面へ描画する。
- 表示後へ移る際は終了直前の同期状態を専用フラグで保持する。色変えの最終文字などを解除してから
  表示後アニメーションを開始しない。
- 短時間に複数の次セリフが来た場合の保持バッファ数と破棄規則は未決定。

### 同期

- 今後の拡張を最優先する。文字色、背景、下線、帯、光沢などを発音位置へ同期させる基盤とする。
- 同期基準は効果ごとに選ぶ。LAB発音要素を使う効果と、無音を除かずセリフ全時間を使う効果を分ける。
  すべての同期効果へ一律に無音除外を適用しない。

#### 同期候補：発音中文字

- 文字色変更：実装・実証済み。
- 文字拡大：実装済み。発音中の1文字だけを拡縮し、軌跡では状態を保持する。
- 文字ジャンプ：実装済み。発音位置の文字を上へ跳ねさせ、標準では着地、軌跡では位置を保持する。
- 文字振動：発音中の文字だけを細かく揺らす。
- 発光：実装済み。文字単位のぼかし輪郭を字形表面へ重ね、標準では復帰、軌跡では保持する。サイズは
  発光量倍率として100%を基準、80%を0.8倍、120%を1.2倍とする。
- 前面：実装済み。背面と同じ形状のマーカーを文字より前面へスクリーン合成し、指定色のライトとして
  文字を隠さず明るくする。標準では移動し、軌跡では通過領域を保持する。
- 縁取り強調：発音中だけ輪郭を太くする。
- 透明度強調：非発音文字を少し薄くし、発音中文字を通常濃度にする。
- 色のパルス：発音開始で明るくし、次の音までに戻す。

#### 同期候補：発音位置

- 背景四角：実装・実証済み。
- 下線：発音位置の文字幅へ合わせて移動する。
- マーカー：文字背面へ蛍光ペン状の帯を表示する。
- 光点：発音位置を中心に小さな光を移動させる。
- スポットライト：現在位置周辺だけを明るくする。
- カーソル：縦線または三角形を文字の下へ表示する。
- 波紋：発音位置を中心に円または四角を短く広げる。
- 音量メーター風：文字背面の高さを発音ごとに変化させる。

#### 同期候補：セリフ全時間

- カラオケ塗り：左から右へ文字色を連続的に塗り替える。
- 下線進行：セリフ全体の進捗に合わせて下線を伸ばす。
- 背景帯進行：行単位の背景帯を左から右へ伸ばす。
- 光沢走査：現在フレーム位置に合わせ、セリフ全体を光沢が横切る。
- グラデーション移動：読み進行に合わせて色境界を移動する。

#### 同期の実装優先順位

1. 下線
2. マーカー
3. 発音中文字拡大
4. 発光
5. カラオケ塗り
6. 文字ジャンプ

上記優先対象を基に、色変え・前面・背面・下線・拡大・発光・ジャンプの7種類について標準／軌跡を実装済み。
可変幅文字、句読点、空白を正しく扱うため、文字変形系は完成画像の矩形分割ではなく独立文字レイヤーを使用する。

### 常時

- 汎用的に動かし続ける効果は用途が限られるため削除し、常時は感情表現専用とする。
- 主用途を感情表現とする。Moduleから受信済みの`emote`を利用し、`常時 感情表現`がOFFなら感情を無視、ONなら効果を自動選択する。
- 感情プリセット名は`AviUtl2PluginLib/Lib/Emotion/EmotionCategory.pas`で通常・喜・怒・哀・楽へ共通変換する。PSD設定画面の既存キーワード規則を採用する。
- 怒（怒り、おこ、ツンツン、ツンギレ、熱血、不機嫌、つよつよ）は108%へ拡大して強く揺らす。
- 哀（悲しみ、かなしみ、泣き、びえーん、なみだめ、恐怖、おどろきなど）は96%へ縮小して細かく震えさせる。
- 喜（喜び、あまあま、わーい、元気）と楽（うきうき、たのしい、楽、楽々）は10pxのジャンプを繰り返す。通常・未対応感情は無加工。
- 複数セリフ時は最新側の感情を本文全体へ適用する。
- 揺れ、震え、ジャンプには速度調整が必要なので`常時 速さ`は残す。
- 手動の`常時 種類`、`常時 値1`～`常時 値3`、ふわふわ等の候補と処理は削除済み。

## 想定する描画・加工順

1. 旧セリフの表示後用一時バッファを背面へ描画する。
2. 現在セリフの常時処理、主に感情表現を評価する。
3. 現在セリフの同期処理を適用する。
4. 現在セリフの表示前、または保持した旧セリフの表示後による最終加工を合成する。

表示後用一時バッファは未実装。感情を含む常時変換を先に計算し、その後へ表示前／表示後の
透明度を掛ける既存の加算順は維持する。

## 次に行う実装候補

1. `文字単位 / なめらか`が意味を持つ同期種類を順に選び、必要な種類だけ2方式へ対応する。
2. 表示後用一時バッファを追加し、新セリフの背面で旧セリフの表示後を継続できるようにする。

## ビルドと確認

- Delphi 13 / Win64 / Debugを使用する。
- ModuleとSerifDrawは通常のPostBuild込みビルドでAviUtl2の配置先へ出力する。
- 主な専用テストは`AviUtl2PluginLib/Serif/Plugin/Draw/Tests`にある。アニメーション項目、状態遷移、共有受信、
  同期フレーム位置、設定、配置、枠、配役名を変更した場合は対応テストを再実行する。
- 実機確認にはAviUtl2の再起動が必要。

## 描画負荷

- 設定画面の背景プレビュー用フレーム取得は、初回、対象オブジェクト変更時、同じフレームへ250ms以上
  留まった時だけ行う。再生中にGPU画像全体を毎フレームCPUへ読み戻さない。
- フィルタオブジェクトは入力と同じ画像サイズを維持する必要があるため、現在のCPU出力経路では
  `GetImageData`と`SetImageData`による全画面転送が残る。次段階の大幅改善には、取得したD3D11
  フレームバッファへ文字・枠をGPU上で直接アルファ合成する経路が必要。
