# PSDArtEditor 通信仕様

## 接続先

編集フォームごとに `PSDArtEditor.<PID>.<GUID>` を作成します。
Windows named pipe `\\.\pipe\<pipeName>` に UTF-8 / message mode / duplex で接続します。
接続情報は `%LOCALAPPDATA%\PSDArtEditor\pipes\*.json`、
AI ジョブではそのジョブの `connection.json` にも記録します。
プロセス名を AIArtToPSD に限定しないでください。ホスト EXE が実行プロセスです。
PID とフォームごとの GUID を選び、status の fileName で対象 PSD を確認してください。
フォーム破棄時には pipe worker を終了し、その connection ファイルを削除します。

要求と応答の形式は ArtPipeProtocol の schemaVersion=1 です。

```json
{"schemaVersion":1,"requestId":"unique-request-id","command":"status","args":{}}
```

成功応答は `ok:true,data:...`、失敗応答は `ok:false,error:{code,message}`。
requestId は応答にそのまま返ります。入力は UTF-8 最大60KB、文字数30000、深さ32。
重複 JSON key は拒否します。1回の要求を1メッセージとして送信してください。

## コマンド

| command | args | 内容 |
| --- | --- | --- |
| status | jobId(任意) | fileName、managed、canEdit、modified、documentId、revision、exchangeRoot、supportedCommands、AI状態 |
| document | なし | 寸法・レイヤー階層・id・name・visible・opacity・bounds・hasMask・selectedLayerId |
| update-layer | documentId, ifRevision(string), layerId, name/visible/opacity(任意) | 属性変更。外部PSDのopacity指定は拒否 |
| save | documentId, ifRevision(string) | 最終差分があるときだけ保存 |
| rename-file | documentId, ifRevision(string), fileName | 管理PSDのファイル名変更。保存先ディレクトリ変更は禁止 |
| new-from-png | documentId, ifRevision(string), fileName | 管理PSDをPNGの原寸キャンバスと画像で初期化。保存先PSDパスは維持。未保存変更があれば拒否 |
| import-png | documentId, ifRevision(string), fileName, parentId | PNGを原寸で追加。parentId=""は最上位、グループIDはその先頭へ追加 |
| replace-png | documentId, ifRevision(string), fileName, layerId | 指定画像レイヤーをPNG原寸で置換。左上座標・名前・表示・不透明度を維持 |
| move-layer | documentId, ifRevision(string), layerId, x, y | 画像の左上をキャンバス座標へ移動。画像マスクも同じ差分で移動 |
| create-group | documentId, ifRevision(string), parentId, name, exclusive(boolean) | 指定階層の先頭へグループ追加。exclusive=trueなら名前へ*を付ける |
| select-part | documentId, ifRevision(string), layerId | 指定した*付きレイヤーだけを同じ親の中で表示。外部PSDでも使用可能 |
| undo / redo | なし | ローカル編集の復元。revisionは戻さず古い結果を無効化 |
| export | prompt, workspace(任意) | ホストのexchangeRoot配下にPNG/JSONを作成 |
| import | jobId | 当該ジョブのresult.jsonを検証して取り込み |
| progress | jobId,state,message,progress | AI進捗通知 |
| cancel | jobId | 当該ジョブの中止 |
| recover | directory | 書出し時点の文書を復元。元PSDのパスとSHA-256を確認し、同じPSDを開き直した後でも再開 |

new-from-png / import-png / replace-png / move-layer / create-group と、
export / import / progress / cancel / recover は管理PSDだけに許可します。
外部PSDは status / document / 名前・表示変更 / select-part / save / undo / redo を使用できます。
編集権限は status.managed で判断してください。canEdit は名前・表示変更が可能という意味です。

更新要求には直前の document 応答の documentId と revision を指定してください。
古いdocumentId/revisionは拒否します。保存は再読込で新しいdocumentIdを発行するため、
保存後には改めて document で取得してください。名前・補助記号変更で排他可視状態は変化しません。
可視をtrueへ切り替えた排他 (*) レイヤーについては同じ親の排他レイヤーの可視を切り替えます。
select-partは対象が既に可視でも兄弟の排他状態を揃えます。

## 直接操作と送信スクリプト

[Send-ArtCommand.ps1](Send-ArtCommand.ps1)をPowerShell 7で使用できます。
status.supportedCommandsは接続先が実装しているコマンド名の一覧です。
PNG操作のfileNameはローカルPNGのフルパスです。UIで選択中の項目には依存せず、
layerIdまたはparentIdで対象を指定します。追加したレイヤーIDは応答のselectedLayerIdで取得できます。
document.layersは親から子へのtopmost-firstで、kindは0=画像、1=グループ、2=区切りです。
bounds/maskBoundsは元キャンバス上の整数座標です。move-layerのx/yは-30000～30000。

```powershell
$sender = '.\Send-ArtCommand.ps1'
$pipeName = '<接続一覧から確認したpipeName>'
$reply = & $sender -PipeName $pipeName -Command document | ConvertFrom-Json
$args = @{
    documentId = $reply.data.documentId
    ifRevision = $reply.data.revision
    fileName = 'C:\Images\original.png'
} | ConvertTo-Json -Compress
& $sender -PipeName $pipeName -Command new-from-png -ArgsJson $args
```

new-from-pngは現在の管理PSDの内容を置き換えるため、先に保存済みの状態で使用してください。
置き換え後は未保存になり、saveまたは画面を閉じる操作で同じPSDへ確定します。
別のPSDを開く操作と新しいPSDの登録は、ホストのPSD一覧から行います。
切り出し・拡縮・透明余白除去・任意位置への追加や複数変更の一括処理には、
下記のexport/importによるPNG/JSON交換を使用してください。

recoverは未保存変更があると拒否します。書出し時のrequest.jsonへ元PSDのfileNameと
sourceSha256を記録し、元PSDのパスと保存内容が一致するときだけ別セッションでも復元します。
別PSDや書出し後に保存内容が変わったPSDへの復元は拒否します。
旧ジョブにこれらの情報がない場合は同じdocumentIdのセッションだけで再開できます。
取消済みジョブを復元しても取消状態を維持します。再開後のconnection.jsonで現在のパイプを確認してください。

## AI PNG/JSON 手順

1. status / document で管理 PSD と現在の文書を確認します。
2. export の prompt と必要なら workspace を指定し、返された directory を使用します。
3. directory 内の request.json と instructions.txt を読みます。PSDを直接加工せず、PNGと result.json を作成します。
4. result の documentId / ifRevision は export 時の値を保持します。
5. import で結果を取り込みます。PSDへの保存は画面終了または save です。
6. フォームで編集・undo・save後の古いresultは拒否します。再exportしてください。

## result.json の形式

result.json は下記の共通フィールドを必須とします。識別子は request.json の値をそのまま転記し、
ifRevision は10進文字列です。JSON は UTF-8、最大1MB。全PNGを書き終えてから
result.json.tmp を書き、result.json へ名前変更して公開してください。

```json
{
  "schemaVersion": 1,
  "requestId": "<request.jsonと同じ値>",
  "jobId": "<request.jsonと同じ値>",
  "documentId": "<request.jsonと同じ値>",
  "ifRevision": "0",
  "assets": [],
  "operations": [
    {"op":"rename_layer","layerId":"<既存layerId>","name":"新しいレイヤー名"}
  ]
}
```

assets は最大128個、operations は1〜256個です。生成画像が不要なら assets は空配列です。
各asset は assetId / path / sha256 / width / height / pixelFormat="RGBA8" / colorSpace="sRGB" を必須とします。
path はジョブ内の images/ 配下の相対PNGパス（例 images/face.png）、sha256 は完成PNGのSHA-256です。
絶対パス・ジョブ外へ出るパス・再解析ポイントは禁止し、PNG寸法とJSON寸法の一致を検証します。
8bit RGBA、画像メモリ合計128MB以下。異なるassetに同じassetIdは使用できません。

全operation に op / layerId を指定します。
layerId は既存操作ではrequest.jsonに記載された値、新規ではジョブ内で重複しない128文字以内のIDです。
layerOrder は topmost-first。新規項目の parentId="" は最上位、beforeLayerId="" は末尾です。
beforeLayerId は同じ親の既存レイヤーIDを指定します。nameは1〜255文字です。

| op | その他の必須フィールド | 内容 |
| --- | --- | --- |
| add_group | name,parentId,beforeLayerId,visible,opacity | グループ追加 |
| add_layer | name,parentId,beforeLayerId,visible,opacity,assetId,bounds | 画像レイヤー追加 |
| replace_layer | assetId,bounds | 画像レイヤー置換 |
| rename_layer | name | 名前・補助記号のみ変更（可視状態の自動変更なし） |
| set_attributes | visible,opacity | 表示状態・不透明度変更 |
| select_part | なし | 排他(*)レイヤーの表示切替 |

visible はJSON boolean、opacity は0〜255の整数です。
bounds は {"left":0,"top":0,"right":1024,"bottom":1024} のような整数の矩形で、
画像operationは正の幅・高さを必要とします。
既存レイヤーには未知のPSD情報を保持するため、既存layerIdを再利用してください。

add_layer/replace_layer の任意属性は resample(boolean), sourceBounds(元PNG内の矩形),
trimTransparent(boolean), coordinateSpace("canvas"または"workspace")です。
画像boundsとPNG/sourceBoundsの寸法が異なる場合はresample=trueが必須です。
workspaceはexport時に発行された正方形座標を使用し、アプリが元キャンバスへ逆変換します。
workspace.sourceLayerId は既存画像IDまたは""（合成画像）、sizeは発行された正方形寸法、
boundsは元キャンバス上の正方形範囲です。
目・口・髪などの部品ごとに中央へ寄せず、共通の座標枠を保持してください。
再調整時は既に縮小したPNGを再縮小せず、生成した元PNGとsourceBoundsから変換してください。

正確な検証の実装は `Integrations/AIExchange/ArtExchange.pas` の schemaVersion 1 を正とします。
ユーザーが手順を渡すための D&D UI やクラウドAPIは含みません。
